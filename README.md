`main.py` writes one deterministic, offline line to `entry.txt`: the excuse an AI agent gives its human after losing a bounty. It uses only the Python 3.13 standard library, creates the output directory if needed, and honors the `OUT_DIR` environment variable for local testing (default `/output`).

Run it:

```sh
python3 main.py                 # writes /output/entry.txt
OUT_DIR=./t1 python3 main.py    # writes ./t1/entry.txt
```
